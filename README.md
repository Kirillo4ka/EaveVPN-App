## 🌟 Ключевые возможности

- 🔐 **Приватная синхронизация:** автоматическая загрузка и обновление зашифрованных серверов прямо в память приложения.
- ⚡ **Ультра-быстрый TCP Handshake замер:** реальный замер доступности и задержки серверов за считанные миллисекунды.
- 🛡 **Продвинутый обход блокировок:** автоматическая маскировка Client Fingerprint (uTLS Chrome) для протоколов Reality, Vision, Trojan, Hysteria2 и VLESS.
- 🚀 **Минималистичный интерфейс:** удобное боковое меню с 3 разделами — Главная страница, Список локаций и Настройки.
- ⚙️ **Системный TUN-режим:** полноценная маршрутизация всего системного трафика Windows и Android.
